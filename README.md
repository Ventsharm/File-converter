# File Converter

This GitHub Pages site directs visitors to the native File Converter Android app. The browser converter and PWA install manifest have been retired.

- Website: https://ventsharm.github.io/File-converter/
- Google Play: https://play.google.com/store/apps/details?id=io.github.ventsharm.fileconverter

The landing page follows the KDP Book Cover Converter landing-page layout. `service-worker.js` only retires this app’s previous offline cache and unregisters itself; it does not cache the landing page. The previous web source remains available in Git history. Native Android source is maintained separately in the private Android builder repository.
